I did this as the practice associated with Vruddhi.
**Class Workout: Collaborative GitHub Project**
Create a GitHub repository and collaborate with one teammate on the project.
**Requirements:**
1. One student creates a GitHub repository and adds the teammate as a collaborator
2. Both students clone the repository to their own computers
3. Both students create/modify different files in the project
4. Each student must:
○ Create changes
○ Stage the changes
○ Create a commit
○ Push the changes to GitHub
○ Pull the latest changes from GitHub
5. The teammate must create a feature branch and make a change to the project
6. The teammate must push the branch and create a Pull Request on GitHub
7. The repository owner must review the changes and accept/merge the Pull Request
8. Both students must update their local main branch after the merge

**Class Workout: Part II**
Continue working on the same GitHub project
Create a situation where both team members modify the same part of the same file
**Requirements:**
1. Both students start from the latest version of the project
2. Both modify the same section/line of the same file independently
3. One student pushes their changes first
4. The second student attempts to push their changes and encounters a conflict
5. Pull the latest changes from GitHub
6. Identify and manually resolve the merge conflict
7. Stage the resolved file
8. Create a commit for the conflict resolution
9. Push the resolved version to GitHub
10. Verify that the final project contains the required changes from both students
